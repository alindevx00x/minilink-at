# ⚡ MiniLink — URL Shortener, Dynamic QR Codes & Real-Time Analytics

**Live Platform:** [https://minilink.at](https://minilink.at)

**MiniLink** is a modern link management platform for creating branded short URLs, dynamic QR codes, and real-time click analytics — built for speed, security, and conversion.

---

## ✨ Key Capabilities

- **Smart URL Shortening**
  - Instant short links with optional custom aliases and custom branded domains
  - Configurable HTTP redirects (`301` Permanent, `302` Temporary, `307` Temporary Preserve Method)
  - Optional link expiration dates, password-protected links, and UTM parameter support
  - Conditional targeting rules by device, country, or browser language
  - Built-in URL security scanning, loopback protection, and domain/keyword safety checks

- **Dynamic QR Code Studio**
  - High-resolution **SVG** and **PNG** QR code generation
  - Custom foreground/background colors, corner styles, and center brand logos
  - Link-backed QR codes with full scan and click telemetry

- **Real-Time Analytics**
  - Live click & unique visitor tracking with automatic dashboard updates
  - Bot and crawler filtering separated from human traffic metrics
  - Geographic city and country breakdowns, devices, operating systems, browsers, languages, and referrers
  - CSV analytics exports and REST API analytics endpoints

- **Developer & SaaS Ready**
  - Token-authenticated REST API (`v1`) and webhook notifications for click events
  - Tiered subscription plans, team/user link organization, and multi-language interface support
